# バグ報告: プレイヤー操作・キャッシュ状態・ウィンドウ復元

## 症状と期待動作

- リピートメニューのアイコン横に余分な開閉記号が表示されていた。
- ライブラリ全体を明示的にランダム再生する機能がなく、外部ライブラリ切断時にキャッシュへ意図的に切り替えられなかった。
- キャッシュ画面は曲数だけでストレージ使用量を表示していなかった。
- 通常ウィンドウの位置と大きさを次回起動時へ明示的に復元していなかった。

期待動作は、隣接した明確なシャッフル／リピート操作、有界な全体ランダムとキャッシュへの切り替え、キャッシュ容量表示、前回の通常ウィンドウフレーム復元です。

## 再現根拠

提供画像で余分なリピート記号と件数だけのキャッシュヘッダーを確認しました。ソースでは開閉記号を隠していないボーダーレス `Menu`、一覧内だけのシャッフル、`COUNT(*)` のみのキャッシュ集計、通常ウィンドウ保存キーの欠如を確認しました。

## 影響

再生操作の理解しやすさ、オフライン再生、ストレージ把握、再起動後の継続性に影響しました。認証情報やメタデータの保存経路は変更していません。
