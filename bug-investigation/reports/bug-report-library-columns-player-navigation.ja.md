# バグ調査: ライブラリ情報列とプレイヤー遷移の不足

## 概要

- **実際:** 曲／アルバム一覧にリリース年、アーティスト一覧にジャンルがなく、プレイヤーのメタ情報から移動できなかった。
- **期待:** 保存可能な任意列で情報を表示し、プレイヤーからアルバム／アーティストへ移動できる。
- **影響:** 基本情報の確認にも詳細画面や再検索が必要だった。

## 再現

1. 曲、アルバム、アーティストを開く。
2. 表示列メニューを開く。
3. リリース年またはジャンルがないことを確認する。
4. 曲を再生し、ジャケット、曲名、アーティスト名をクリックする。
5. ライブラリ遷移が起きないことを確認する。

## 証拠

ソース調査で列enum、DB集計、テーブル、共通プレイヤーに経路がないことを確認した。ページング、ソート、列保存、共通プレイヤー操作を回帰テストへ追加した。
