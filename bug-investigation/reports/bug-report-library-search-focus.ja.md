# バグ報告: ライブラリ検索のフォーカス消失と幅変更

- 発生日: 2026-07-29
- 重要度: 操作性に大きく影響
- 対象: macOS版ライブラリ上部の検索欄

## 再現手順

1. アルバムやアーティストなどのライブラリ項目を開く。
2. 上部の検索欄をクリックする。
3. 短い検索文字を入力する。
4. 280 msのインクリメンタル検索待ち時間を経過させる。

期待: 続けて入力でき、検索欄の大きさも変わらない。

実際: フォーカスが外れる場合があり、検索中UIが出ると検索欄の幅が広がる。

## 根拠

検索欄が親 `ViewThatFits` の両候補に含まれ、条件付きの検索中ラベルが現れると可変幅が変わっていた。デバウンス後には表示セクションも「曲」へ変わる。この状態・寸法変更によってSwiftUIが別レイアウト候補を選び、フォーカス中のテキスト欄を含むサブツリーが差し替わっていた。
