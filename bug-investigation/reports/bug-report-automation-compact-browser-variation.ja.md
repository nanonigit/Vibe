# バグ報告: 自動処理・狭幅表示・ブラウザ翻訳・表記ゆれ修正

## 症状

- メタデータ自動処理をチェックしても別の開始・停止ボタンがあり、チェックが処理状態を表していなかった。
- 中央ペインや右ペインを狭くすると、操作部品が重なったり欠けたりした。
- ブラウザ翻訳を永続的にオフにできず、表示中の翻訳状態から切り替えられなかった。
- 表記ゆれ候補は確認できても、上下どちらの表記へ統一するか選べなかった。

## 再現根拠

1. 自動処理をオンにし、別の開始・停止ボタンが残ることを確認する。
2. 中央または右ペインを狭くし、1行内の操作部品が競合することを確認する。
3. 外部記事を開き、翻訳の永続オン・オフがないことを確認する。
4. 表記ゆれ候補を開き、「候補から除外」以外の統一操作がないことを確認する。

## 期待結果

- チェックだけで開始・停止し、進捗は受動表示にする。
- 重なる前に配置を切り替え、プレイヤー操作は省略しない。
- 翻訳設定を保存し、現在ページへ即時反映し、設定画面とブラウザ状態表示のどちらからも切り替えられる。
- 確認後、既存の安全なメタデータ書込経路で上下どちらの値にも統一できる。
