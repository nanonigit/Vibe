# 修正記録: 安定したライブラリ検索

## 修正

- 単一の検索欄を `ViewThatFits` の候補外へ移動した。
- `ContentView` 所有の `FocusState` を追加し、検索欄へバインディングを渡した。
- 最初のフレームから検索欄を360ポイントの固定幅にした。
- 条件付き検索中テキストを廃止し、常設16ポイント領域のスピナーを透明度で切り替えるようにした。
- フォーカス所有、検索欄の単一性、固定幅、安定した進捗領域を確認するソース回帰テストを追加した。

## 維持した動作

- 280 msデバウンス、セクション遷移、DB検索、消去操作、アクセシビリティラベルは維持している。

## 検証

- macOS全テスト: 163件成功。
- Releaseビルド: Apple Silicon（`arm64`）で成功。
- アドホック署名したReleaseアプリを `/Applications/Vibe.app` へインストールして正常起動し、入力前から検索欄が広い状態で表示されることを画面確認した。
