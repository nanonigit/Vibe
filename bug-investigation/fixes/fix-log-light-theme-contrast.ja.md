# 修正ログ: ライトテーマのコントラスト

- 症状: ライト背景へ変わっても文字やAppKit標準部品がダーク配色のままで、文字が読めなかった。
- 根本原因（5 Whys）: SwiftUIのsurface色だけ変更し、ネイティブウインドウ外観がダークのままだったため、セマンティック文字色と標準部品が誤った外観を参照した。
- 修正: テーマを直接監視するプレイヤービュー内の同期部品から、保存テーマ変更時に`NSApplication.appearance`とVibeの全ウインドウ外観を更新する。古い値を保持する親color scheme指定は外し、ライト→ダークとダーク→ライトの両方向を成立させる。
- 検証: ライト3テーマ、入力欄・テーブルヘッダー、arm64 Releaseビルド、実アプリ再起動を確認する。
- 再発防止: 今後のテーマ追加ではSwiftUI surfaceとAppKit標準部品の両方を検証する。
