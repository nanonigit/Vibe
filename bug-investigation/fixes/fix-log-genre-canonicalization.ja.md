# 修正記録: ジャンル表記の標準化

## 変更内容

- 報告画面に表示されていた日本語ジャンルの英語別名を追加しました。
- 中黒、スラッシュ、ハイフン、空白、全角記号、大文字小文字を無視する照合キーを追加しました。
- 未登録の日本語を勝手に削除せず、そのまま残す安全なフォールバックへ変更しました。
- 生のジャンル一覧と件数を、同じ英語標準名の下へ統合しました。
- 選択した標準ジャンルから元の別名を解決し、曲・アルバム・アーティスト・容量を同じ範囲で検索するようにしました。
- 取り込み時とDB直接更新時にジャンルを標準化しました。
- `year` 列追加後に崩れていた既存のテスト用曲データ挿入も修正しました。

## 安全性

実ライブラリの走査や音源ファイルのタグ書き換えは実行していません。検証は一時テストDBとarm64ビルドだけで行います。
