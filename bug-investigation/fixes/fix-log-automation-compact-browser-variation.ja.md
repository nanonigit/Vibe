# 修正記録

- 自動処理設定は、オン保存で開始、オフ保存でキャンセルするようにした。
- 重複する開始・停止ボタンを、受動的な状態表示へ置き換えた。
- 横幅が足りないとき、ライブラリヘッダーを縦配置へ切り替え、検索窓を独立した可変幅の行にした。
- 共通プレイヤーは狭幅配置へ切り替えても、ジャケット、曲情報、シャッフル、リピート、ミニプレイヤー、音量、曲送り、シークを残した。
- 外部記事翻訳を保存設定にし、「表示」とクリック可能なブラウザ状態表示へ接続した。変更時は現在の原文／翻訳ページを即時再読込する。
- 表記ゆれの各値に、確認付きの統一操作を追加した。完全一致曲を取得し、既存の安全な一括メタデータ書込経路へ渡す。
- 各修正の回帰確認を追加した。
