# Recurrence Prevention

- Test that icon-only menus explicitly hide their native indicators.
- Represent playback scope separately from shuffle enabled state.
- Keep large-library selection in indexed database queries; never materialize the library.
- Treat a cache record as playable only after checking the file exists.
- Add byte totals whenever a storage-backed item count is exposed.
- Persist normal and compact window frames as separate concepts and constrain restored frames to visible screens.
