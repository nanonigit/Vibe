# Prevention: Metadata Presentation Contracts

1. When automation adds stored metadata, review list columns, sorting, search, detail views, and navigation together.
2. Aggregate derived list values in SQL with deterministic tie-breaking and bounded paging.
3. Keep shared player actions in the shared control so inspector and mini-player cannot drift.
4. Cover every new column through model, query, persistence key, menu, header, cell, width, and sort tests.
