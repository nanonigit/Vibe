# Prevention: Genre Canonicalization

- Keep one canonicalization boundary for import, direct updates, facets, counts, and navigation filters.
- Add alias regression cases whenever a new externally sourced genre spelling appears.
- Never remove unknown non-Latin text merely to satisfy an English-only presentation rule.
- Reduce large libraries to distinct labels before applying Swift normalization.
- When the track schema gains a column, update and exercise every direct SQL fixture in the same change.
