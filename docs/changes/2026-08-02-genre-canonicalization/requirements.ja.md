# ジャンル標準化 要件

## 目的

元タグの言語、大文字小文字、空白、中黒、スラッシュ、ハイフンが異なっても、信頼できる1つの英語ジャンル体系として表示します。

## 要件

1. ジャンル画面とサイドバー件数は、同義の元タグを1つの英語標準名へ統合します。
2. 大文字小文字を区別せず、Unicodeを考慮し、意味を変えない区切り記号の差を同一視します。
3. カタログにある日本語ジャンルは明示的な英語名へ変換し、未知の日本語を黙って削除しません。
4. ジャンル詳細には、選択した標準ジャンルに属する全表記の曲を含めます。
5. 新規スキャン、手動編集、AI登録はローカルDBへ標準ジャンルを保存します。
6. 統合表示だけのために音源ファイルを走査・書換しません。明示的なメタデータ整理は既存の200曲単位と保留編集の安全経路を維持します。
7. 全曲を一括でメモリへ読み込みません。
8. 未コミットの既存変更とGeminiキーのアプリ内保護DB方式を維持します。

## 受入例

- `jazz`、`JAZZ`、`ジャズ` -> `Jazz`
- `Smooth-Jazz`、`Smooth Jazz`、`スムース・ジャズ`、`スムースジャズ` -> `Smooth Jazz`
- `J POP`、`J-POP`、`j-pop` -> `J-Pop`
- `ソウル／R&B`、`Soul / R&B`、`soul-r&b` -> `Soul / R&B`
- `ヴィジュアル系ロック` -> `Visual Kei Rock`
