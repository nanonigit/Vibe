# サイドバー初期値と安定した検索欄の要件

## 要件

- サイドバー設定が未保存のとき、ライブラリには「キャッシュ、アーティスト、アルバム、曲、ジャンル、お気に入り」をこの順で初期表示する。
- 「次に再生」「最近追加した曲」「フォルダ」は、未設定の初期状態だけ非表示にする。
- 保存済みの並び順・表示設定は、非表示項目が0件として明示保存された場合も含めて優先する。
- インクリメンタル検索によって表示セクションや結果が更新されても、検索欄のキーボードフォーカスを維持する。
- 検索欄は入力前から十分な幅で表示し、検索中表示によって幅を変えない。
- 検索中表示と消去ボタンは、フォーカス中のテキスト欄を構造的に差し替えない。

## 受け入れ条件

- 初期順序と初期非表示項目を回帰テストで固定する。
- 保存済みサイドバー設定の読み込み動作を維持する。
- 安定して存在する親ビューが検索フォーカスを所有し、検索コンポーネントへ渡す。
- 検索欄を固定幅にし、検索進捗用の固定領域を常に確保する。
