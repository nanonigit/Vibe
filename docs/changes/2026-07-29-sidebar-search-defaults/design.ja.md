# サイドバー初期値と安定した検索欄の設計

## サイドバー初期化

`LibraryViewModel` に初期順序と初期非表示集合を明示する。初期化時は、対応するDB設定が存在しない場合だけ初期値を使う。保存値が空文字の場合はユーザーが「すべて表示」を選んだ有効な設定として扱い、未設定と混同しない。

## 検索欄の同一性とレイアウト

ライブラリの選択セクションが変わっても存続する `ContentView` が検索用 `FocusState` を所有し、`LibrarySearchField` にバインディングを渡す。検索欄は最初のフレームから固定幅にする。検索進捗領域は常にビュー階層へ置き、追加・削除ではなく透明度だけを変える。これにより入力中に `ViewThatFits` が別レイアウトへ切り替わるのを防ぐ。

消去ボタンは固定幅コンテナ内に出してもコンテナ寸法を変えない。検索実行とデバウンスは変更しない。

## 根本原因の要約

以前は「検索中…」ラベルが現れると可変幅の固有サイズが増え、親の `ViewThatFits` が別候補へ切り替わる場合があった。その際に検索サブツリーが再生成され、AppKitのテキスト欄がファーストレスポンダーを失っていた。寸法の固定と親所有のフォーカスで両方の要因を除く。
