# 再生機能とキャッシュ状態の要件

## 機能要件

- リピート操作は余分な開閉記号を重ねず、1つの明確なアイコンとして表示する。
- シャッフルとリピートは通常プレイヤーとミニプレイヤーの両方で隣接させる。
- シャッフルメニューから、接続中のライブラリ全体をランダム再生できるようにする。
- 設定済み音楽ドライブが1つも接続されていない場合は、実際に再生できるローカルキャッシュだけを対象にする。
- 全体ランダム再生でライブラリ全件をメモリへ読み込まない。
- キャッシュ画面のヘッダーに曲数とキャッシュファイル合計容量を表示する。
- 右ペインの詳細領域では、上部プレイヤーに表示済みの曲名・アーティスト名を重複表示しない。
- キャッシュ追加・削除後は既存のサイドバー集計更新経路で容量も更新する。
- 次回起動時に、前回の通常プレイヤーのウィンドウサイズと画面上の位置を復元する。
- ミニプレイヤーのフレームで通常プレイヤーの保存値を上書きしない。
- 復元したフレームは現在接続中の画面内に収まるよう補正する。

## 制約

- 現在のリスト単位シャッフルとリピート動作を維持する。
- DBにだけ残った古いキャッシュ記録を再生対象にしない。
- Geminiの認証情報はアプリ内保護DB方式を維持する。
