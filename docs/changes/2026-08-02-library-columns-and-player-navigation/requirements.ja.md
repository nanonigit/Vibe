# 要件: ライブラリ列とプレイヤー遷移

## リリース年

- 曲一覧の既存「表示項目」から、永続化される「リリース年」列を選べること。
- 既存のページングDB経路で年をソートし、ページをまたいでも順序が安定すること。
- 年がない曲は空欄ではなく控えめなプレースホルダーを表示すること。
- アルバム一覧に既にあるリリース年列は維持すること。

## アーティストのジャンル

- アーティスト一覧で、永続化される「ジャンル」列を選べること。
- ライブラリ内で最も多い空でないジャンルを代表ジャンルとして表示し、同数時も順序が安定すること。
- 全曲をメモリへ読み込まず、アーティストをジャンルでソートできること。
- ジャンルがない場合は控えめなプレースホルダーを表示すること。

## プレイヤーからの遷移

- 再生中のジャケットまたは曲名を押すと、その曲のアルバムを開くこと。
- アーティスト名を押すと、そのアーティストページを開くこと。
- 未再生時、またはアルバム／アーティストが空の場合は操作できないこと。
- 右ペインとミニプレイヤーで同じ動作になること。

## 安全性

- ページング、列幅の保存、戻り先状態、APIキーの保護DB保存を壊さないこと。
- 検証で実ライブラリを走査・変更しないこと。
