# 設計: ライブラリ列とプレイヤー遷移

## UI調査

Lazyweb のデスクトップ音楽ライブラリ調査では、行を高くせず、年をコンパクトで任意表示の表列として扱う構成が適していました。レポート: https://www.lazyweb.com/report/lazyweb/27217aa7-2fc2-4a41-b591-c40085fd439c/

## データモデル

- `TrackSort.year` を追加し、既存のインデックス／ページング対応曲クエリを使う。
- `ArtistSummary` に `genre` を追加し、互換性のため既定値は空文字にする。
- フィルタ済みCTEからアーティスト集計を作り、空でないジャンルを曲数、次に大文字小文字を無視した名称で順位付けし、1位を代表ジャンルとして結合する。

## UI

- 曲列の初期順で「リリース年」をアルバムの後に置き、85ポイントの幅を保存する。
- アーティスト表では「ジャンル」をアーティストと件数の間に置き、表示切替・幅変更・ソートを可能にする。
- ジャケット、曲名、アーティスト名を見た目を崩さないプレーンボタンにする。ジャケット／曲名は共通アルバム遷移、アーティスト名は既存のアーティスト遷移を呼ぶ。
- 余計な表示を増やさず、ヘルプとアクセシビリティラベルで操作を説明する。

## 遷移

共通ヘルパーは既存のアルバムセルと同じ `AlbumSummary` 識別情報を作り、`openAlbum` を呼ぶ。これにより既存の戻り先スタックを維持し、別の遷移実装を増やさない。
