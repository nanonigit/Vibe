# Vibe 0.16.0 リリース設計

## ドキュメント

`README.md`を英語版の基準、`README.ja.md`を日本語版とする。機能は大規模ライブラリ、オフライン保管、再生・練習、発見、メタデータ安全性、ジャンル自動登録、外観に整理する。インストールはHomebrewを先に、バージョン付きGitHubアーカイブを次に案内する。

## バージョンと配布物

アプリのInfo.plist元データとXcodeGen定義をバージョン0.16／ビルド16にする。Releaseビルドは`platform=macOS,arch=arm64`を対象とする。署名済み`Vibe.app`を`ditto`でZIP化し、展開後の内容を確認してSHA-256を計算する。

## 公開順序

1. ソースとドキュメントを検証する。
2. `main`をコミットしてプッシュする。
3. タグ／リリース`v0.16.0`を作成し、アーカイブをアップロードする。
4. リモート配布物のチェックサムを確認する。
5. そのチェックサムでHomebrew Caskを更新し検証する。
6. Tapをコミットしてプッシュし、利用可能なHomebrew監査・スタイル検査を実行する。

## 安全境界

ビルド生成物はGitへ含めない。`.agents/`と`skills-lock.json`はVibe製品ソースではなくローカルのエージェント用ツールなので除外する。Gemini認証情報は引き続きアプリ内保護DBを使用する。
