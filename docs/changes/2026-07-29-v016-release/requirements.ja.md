# Vibe 0.16.0 リリース要件

- 英語版と日本語版のREADMEを現在のアプリ動作に合わせて更新する。
- 相互言語リンクを維持し、Homebrewと直接ダウンロードの両方を案内する。
- ハイブリッドジャンル判定、6種類の外観テーマ、安定した検索、BPM・練習機能、キャッシュ状態、ウインドウ復元など、テスト済みソースに存在する機能だけを記載する。
- アプリのバージョンを0.16、ビルド番号を16にする。
- `Vibe-v0.16.0-macos-arm64.zip` というApple Silicon向けReleaseアーカイブを作成する。
- 公開前にテスト、Releaseビルド、arm64、署名、アーカイブ内容、チェックサムを検証する。
- GitHub Releaseを作成する前にアプリのソースをコミットしてプッシュする。
- 正確な日英リリースノートと検証済みアーカイブでGitHub Release `v0.16.0` を公開する。
- `nanonigit/homebrew-vibe` のCaskを0.16.0と公開アーカイブの正確なチェックサムへ更新し、検証、コミット、プッシュする。
- APIキー、ローカルDB、音源パス、ビルド生成物、プロジェクトローカルのエージェントツールはコミットしない。
