# 外部AIジャンルスキャン設計

スキャン開始時に設定済みプロバイダーのキーをアプリ内保護DBから一度だけ読みます。ライブラリ全件を配列化せずSQLiteから未分類曲をページ取得し、各曲をOpenAIへ順番に送信し、失敗時はGeminiへ切り替えます。1曲のリクエスト完了ごとにメインアクター上で全カウンターを更新してから次へ進みます。

確信度80%未満と、通信・登録失敗を別々に数えます。設定済み外部AIが3曲連続ですべて失敗した場合は、残り秒数を表示して10秒待機し、その後に自動再開します。待機中の停止操作にも即座に応答します。内蔵分類器は再生時の軽量提案には残しますが、明示的な外部AIスキャンでは使用しません。

ジャンル画面には詳細な進捗を表示します。左ペイン下部では既存のコンパクトなバックグラウンド状態表示を再利用し、現在曲と確認・登録・80%未満・失敗件数を表示します。
