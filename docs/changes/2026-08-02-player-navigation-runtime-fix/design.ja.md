# プレイヤー遷移の実機修正 設計

## 根拠

Lazywebで確認したデスクトップ音楽プレイヤーの事例では、ジャケット、曲情報、アーティスト情報を余計なUIを増やさず直接の遷移対象にしています。Vibeにはすでに対象となる表示があるため、レイアウトは維持し、遷移先の意味を強化します。

## 設計

- 既存のプレーンなボタンとラベル全体のクリック領域を維持する。
- ジャケットと曲名は、プレイヤー専用のアルバム遷移メソッドへ接続する。
- アルバムアーティストは、空白除去後の `albumArtist` を優先し、空なら `artist` を使う。
- セクションを切り替える前に、現在の閲覧状態を保存する。
- `.albums` または `.artists` へ明示的に移動し、競合する詳細フィルタを解除してから遷移先を読み込む。
- 既存の戻る履歴を壊さないよう、表やヘッダーの汎用遷移は変更しない。
