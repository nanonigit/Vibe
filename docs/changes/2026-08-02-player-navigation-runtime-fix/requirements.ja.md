# プレイヤー遷移の実機修正 要件

## 目的

再生中プレイヤーを、ローカルライブラリ階層へ確実に移動できる入口にします。

## 要件

1. プレイヤーのジャケットまたは曲名をクリックすると、現在の曲のアルバム詳細を開くこと。
2. 表示中のアーティスト名をクリックすると、そのアーティスト詳細を開くこと。
3. アルバム遷移では `albumArtist` があれば優先し、コンピレーションを含むDBのアルバム分類と一致させること。
4. プレイヤーからの遷移では「アルバム」または「アーティスト」セクションへ明示的に移り、戻る操作用に元の閲覧状態を保存すること。
5. アルバム名やアーティスト名が空の場合は、不正な詳細を開かず操作不可のままにすること。
6. 右ペインのプレイヤーとミニプレイヤーで同じ動作にすること。
