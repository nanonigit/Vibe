# 外観テーマ 要件

- 設定と管理 > 表示で、ダーク3種類・ライト3種類をプレビューから選べる。
- 選択は即時にアプリ全体へ反映し、再起動後も保持する。
- ライトテーマではmacOS標準部品とセマンティック文字色もライト外観へ切り替え、ラベル、入力欄、テーブルヘッダー、メニューを読める状態にする。
- 背景、サイドバー、中央リスト、右ペイン、カード、区切り、選択状態に判別できる階層差を付ける。
- ダークの標準テーマは読みやすいチャコール配色にする。
- 旧 `system` / `dark` / `light` 設定は対応する新テーマへ安全に移行する。
- 状態色、文字のセマンティックカラー、Geminiキーの保護DB保存方式は変更しない。
