# Appearance Theme Requirements

- Settings & Management > Display offers three dark and three light themes with visual previews.
- Selection applies immediately throughout the app and persists across launches.
- Light themes switch native macOS controls and semantic text to light appearance so labels, fields, table headers, and menus remain readable.
- Canvas, sidebar, library, inspector, cards, dividers, and selection states have distinguishable surface levels.
- The default dark theme uses a readable charcoal palette.
- Legacy `system`, `dark`, and `light` values migrate safely to a corresponding new theme.
- Semantic status colors, text semantics, and protected-database Gemini key storage remain unchanged.
