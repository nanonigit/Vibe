# ハイブリッド・ジャンル判定 設計

## 根拠

MusicBrainz公式APIは`inc=genres`でエンティティのジャンルを取得できる。公開サービスは現在、送信元IPあたり平均1リクエスト／秒に制限され、識別可能なUser-Agentが必要なため、Vibe既存サービスの1.1秒間隔を再利用する。

## 処理順

1. 同じアルバム／アーティストの登録済み曲から主要ジャンルをDBで取得する。
2. `LocalGenreClassifier`を実行し、確度80%以上だけ採用する。
3. MusicBrainzで完全一致するrelease groupを検索し、`inc=genres`で最多得票ジャンルを取得する。成功・該当なしを正規化アルバム／アーティスト単位でキャッシュする。
4. 見つからない場合だけOpenAI、次にGeminiへフォールバックする。
5. VibeのライブラリDBだけへ保存し、ジャンル件数と判定元別件数を即時更新する。

## 安全性

- MusicBrainzは既存の1.1秒間隔で逐次アクセスする。
- アルバム名とアーティスト名の正規化完全一致で誤一致を防ぐ。
- 該当なしもキャッシュし、同じアルバムの全曲で再検索しない。
- 各段階でキャンセルを確認する。
