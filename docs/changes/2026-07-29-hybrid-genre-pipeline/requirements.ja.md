# ハイブリッド・ジャンル判定 要件

- 未分類曲をすべて外部AIへ直接送らない。
- 信頼できるライブラリ内一致、高確度ローカル規則、MusicBrainzジャンル、設定済み外部AIの順で判定する。
- 既存ジャンルは変更せず、確度80%以上だけ登録する。
- MusicBrainz結果をアルバム／アーティスト単位でスキャン中キャッシュし、リクエスト制限を守る。
- MusicBrainzに情報がないことは失敗とせず、利用可能な判定元がすべて失敗した場合だけ失敗へ数える。
- 音声は送信しない。Geminiキーはアプリ内保護DB方式を維持する。
- 進捗には現在の判定元と、判定元別の登録件数を表示する。
