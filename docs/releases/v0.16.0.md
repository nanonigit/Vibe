# Vibe 0.16.0

## Highlights

- Added a hybrid genre pipeline that prefers library consensus, local rules, and MusicBrainz before calling a configured external AI provider.
- Added live genre counts, source-specific registration totals, automatic 10-second retry after temporary AI failures, and genre descriptions.
- Added six selectable appearance themes: three dark and three light palettes with readable native controls.
- Added locally detected BPM, guitar/bass TAB video search, editable lyrics, and improved synchronized lyric scrolling.
- Added whole-library shuffle with cached-track fallback while external storage is disconnected.
- Added cache-size reporting and restoration of the previous normal-window size and position.
- Stabilized the library search field so it starts at full width and retains focus while incremental results update.
- Refined the full and mini players, repeat controls, sidebar menus/defaults, table dividers, metadata diagnostics, and inspector resizing.

## Safety and compatibility

- Existing genres are never overwritten by automatic classification.
- Audio is not uploaded for genre classification.
- Gemini credentials remain in Vibe's protected in-app database; this release does not move them to Keychain.
- Large-library operations remain paged or bounded rather than loading the full library into memory.
- ID3v2.2 conversion remains confirmation-gated and validated before the original file is replaced.

## Requirements

- Apple Silicon Mac
- macOS Tahoe 26 or later

The distributed build is ad-hoc signed and is not notarized by Apple. If macOS blocks the first launch, Control-click Vibe in Finder, choose **Open**, and review the warning before continuing.
