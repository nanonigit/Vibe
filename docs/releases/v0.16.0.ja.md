# Vibe 0.16.0

## 主な変更

- ライブラリ内の一致、ローカルルール、MusicBrainzを優先し、最後に設定済み外部AIを使うハイブリッドジャンル判定を追加しました。
- ジャンル件数のリアルタイム更新、判定元別の登録件数、外部AI一時失敗後の10秒自動再試行、ジャンルの特徴説明を追加しました。
- ネイティブ操作部品の視認性を保つダーク3種類・ライト3種類、計6種類の外観テーマを追加しました。
- ローカルBPM判定、ギター／ベースのTAB動画検索、歌詞修正、同期歌詞スクロールの改善を追加しました。
- 外付けストレージ切断中はキャッシュ曲へ切り替わる、ライブラリ全体のランダム再生を追加しました。
- キャッシュ使用量表示と、通常ウインドウの終了時サイズ・位置の復元を追加しました。
- ライブラリ検索欄を安定化し、入力前から十分な幅で表示して、検索結果更新中もフォーカスを維持するようにしました。
- 通常／ミニプレイヤー、リピート操作、サイドバーメニューと初期項目、表の区切り線、メタデータ診断、右ペインの幅調整を改善しました。

## 安全性と互換性

- ジャンル自動判定は既存ジャンルを上書きしません。
- ジャンル判定のために音声をアップロードしません。
- Gemini認証情報は引き続きVibeのアプリ内保護DBへ保存し、Keychainへ戻していません。
- 大規模ライブラリ処理は全曲をメモリへ読み込まず、ページングまたは件数を制限した処理を維持しています。
- ID3v2.2変換は引き続きユーザー確認後に実行し、原本置換前に検証します。

## 動作環境

- Apple Silicon Mac
- macOS Tahoe 26以降

配布物はアドホック署名で、Appleによる公証は行っていません。初回起動をmacOSに止められた場合は、FinderでVibeをControlクリックして「開く」を選択し、警告内容を確認してから続行してください。
